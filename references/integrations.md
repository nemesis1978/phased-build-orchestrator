# Integrazioni esterne (facoltative, mai presunte)

Se sono realmente installate e disponibili, le skill del progetto **Matt Pocock / skills** possono essere usate come acceleratori.

| Esigenza | Skill pertinente | Path nel repo | Nota |
|---|---|---|---|
| Idea circoscritta ma incompleta | `grill-me` / `grill-with-docs` | `skills/productivity/grill-me`, `skills/engineering/grill-with-docs` | intervista per sciogliere ambiguità |
| Grande progetto con percorso incerto | `wayfinder` | `skills/engineering/wayfinder` | mappa decisioni; **non** implementa |
| Formalizzare decisioni in specifica | `to-spec` | `skills/engineering/to-spec` | sintetizza una spec |
| Suddividere il lavoro implementabile | `to-tickets` | `skills/engineering/to-tickets` | ticket e dipendenze |
| Implementare e controllare | `implement`, `tdd`, `code-review` | `skills/engineering/…` | disponibilità e modalità variabili |
| Passare a un'altra sessione/agente | `handoff` | `skills/in-progress/claude-handoff` | documento di continuità, non test |
| Ridurre il contesto nella stessa sessione | `/compact`, **se offerto** | comando della piattaforma | non è sinonimo di handoff |

## Avvertenze

- Questa skill è una **rielaborazione originale** del metodo, con integrazioni di qualità: non è una copia e non è una skill ufficiale di Matt Pocock.
- I nomi e i path delle skill terze possono cambiare: verifica prima di citarli come disponibili.
- Se non sono disponibili, esegui i passaggi equivalenti descritti in questa skill.
- GitHub e Linear sono utili ma **opzionali**: Markdown locale e Git bastano per molti progetti.
- Non presupporre che un tracker esterno sia connesso.
